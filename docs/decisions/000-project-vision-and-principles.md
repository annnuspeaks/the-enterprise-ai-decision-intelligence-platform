# Project Vision & Principles

Build a production-inspired Enterprise AI Decision Intelligence Platform that integrates multiple Machine Learning models into a unified decision-support system for business analytics.

---

## Options Explored

### Option 1
Academic ML Demonstration Project

### Option 2
ML Portfolio with Independent Models

### ✅ Option 3 (Selected)

---

## Reason

- Demonstrates end-to-end ML engineering.
- Solves realistic business problems.
- Portfolio-focused.
- Interview-ready.
- Scalable across Semester 3 and Semester 4.
