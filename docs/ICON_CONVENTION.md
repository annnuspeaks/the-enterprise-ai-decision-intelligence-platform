# Nexora Icon Convention 

Use `lucide-react` for application icons.

- Navigation/menu controls: 20px
- Compact controls / arrows / theme toggle: 18–20px
- Feature icons: 22px
- Model/card icons: 24px
- Dashboard model icons: 28px
- Default stroke weight: 2

Do not mix icon libraries for the same UI role. Keep icon size aligned with the visual hierarchy of the component.
